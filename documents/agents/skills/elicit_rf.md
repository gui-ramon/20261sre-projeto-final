# Skill: Elicitar Requisitos Funcionais (RF)

## Quando usar
Quando o usuário pedir RFs e existir `spec/00_problem.md`.

## Entrada
- `spec/00_problem.md` (obrigatório)

## Passos
1. Identificar as funções principais do sistema para atender aos fluxos críticos.
2. Definir as entradas, processamentos e saídas para cada função.
3. Organizar em IDs RF-NN.
4. Validar contra as restrições em `documents/agents/AGENTS.md`.

## Saída
Arquivo `documents/01_functional_requirements.md` com a lista de RFs detalhados.

## Critérios de Aceitação
- IDs estáveis (RF-01, RF-02...).
- Verbos de ação claros.
- Coerente com o ambiente AWS Learner Lab.
